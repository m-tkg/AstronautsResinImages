# Astronauts Circle Studio

画像を円形に切り抜き、5 列 × 7 行の A4 シートに配置するブラウザアプリです。画像はブラウザのメモリ内で処理し、サーバーへ送信しません。

## 起動

Node.js と Python 3 があれば、追加のパッケージをインストールせずに使えます。

```sh
npm run dev
```

http://localhost:5173 を開いてください。`dist/` はそのまま静的ホスティングにも配置できます。

## GitHub Pages

リポジトリ: https://github.com/m-tkg/AstronautsResinImages （非公開）

`.github/workflows/pages.yml` により、`master` への push 時にテストし、`dist/` のみを GitHub Pages にデプロイします。手動実行にも対応しています。

非公開リポジトリでの GitHub Pages 利用には GitHub Pro 以上の対応プランが必要です。初期設定時点では GitHub API がプラン非対応（HTTP 422）を返したため、サイトは未公開です。対応プランへの変更後、Settings → Pages → Build and deployment → Source で GitHub Actions を選択し、Deploy GitHub Pages ワークフローを手動実行してください。

公開後の URL は https://m-tkg.github.io/AstronautsResinImages/ です。リポジトリを非公開にしても、通常の GitHub Pages サイトはインターネットへ公開されます。選択した画像は引き続きブラウザ内だけで処理されます。

## 操作

1. シートの円をクリックし、JPEG・PNG・WebP などブラウザ対応の画像を選びます。
2. ドラッグまたは矢印キーで位置、スライダーで倍率を調整します。Shift + 矢印キーで大きく移動できます。
3. 「この配置にする」で確定します。登録済みの円をクリックすると、再編集・画像変更・削除ができます。キャンセルすると変更前の状態を維持します。
4. 「PNG を保存」で印刷用シートを書き出します。「A4 で印刷」でブラウザの印刷画面も開けます。

5. 「プロジェクトを保存」で画像と編集内容を `.astronauts.json` ファイルに保存します。「プロジェクトを開く」で読み込むと、続きから編集できます。
6. 「初期化」で確認後にすべての画像と配置を消去し、35 枠を空の状態に戻します。保存済みの PNG やプロジェクトファイルは削除しません。

編集中の内容はメモリ上に保持します。タブを閉じたり再読み込みしたりする前にプロジェクトを保存してください。PNG は印刷用の完成画像で、再編集にはプロジェクトファイルを使用します。

プロジェクトには元画像のデータとファイル名・画像寸法、各枠の拡大率・移動量、用紙設定を保存します。35 個の配列の順序が配置先を表し、空き枠も維持します。画像本体を埋め込むため、元画像を移動しても、別端末でも復元できます。JSON 内の Base64 により元画像の合計容量より大きくなります。画像とプロジェクトはサーバーに送信しません。ファイル形式はバージョン付きで管理しています。

プロジェクトを開くと現在の配置を置き換えます。画像が配置済みの場合は置き換え前に確認します。全データと画像を検証・読み込みできた場合だけ置き換えるため、壊れたファイルでは現在の配置は変更されません。

## 元 PSD と出力寸法

`~/Downloads/astronauts.psd` の画像ヘッダー・解像度リソース・アルファチャンネルを確認して寸法を取得しました。元 PSD や画像の内容はリポジトリに含めていません。

| 項目 | 値 |
| --- | --- |
| キャンバス | 2480 × 3508 px |
| 解像度 | 300 dpi |
| 円の直径 | 283 px（23.96 mm） |
| 最大登録数 | 5 列 × 7 行 = 35 個 |
| 出力 | 白背景の PNG、300 dpi の pHYs チャンク付き |

PSD 内の主な円形領域は 283 × 283 px です。円サイズを維持し、配置は A4 中央に等間隔で整列しています。PSD 内の個々の位置は再現していません。未登録枠・番号・操作ガイドは出力されません。透明な画像部分は白背景になります。

印刷時は用紙を A4、倍率を **100%／実際のサイズ** に設定し、「用紙に合わせる」を無効にしてください。ブラウザから印刷する場合は余白なし・ヘッダーとフッターなしを指定してください。印刷ソフトによっては PNG の dpi 情報を無視するため、印刷プレビューでも倍率を確認してください。実機プリンターでの印刷寸法は未検証です。

## 検証

```sh
npm test
```

寸法と整列、画像の充填・移動制限、PNG の解像度情報と CRC を検証します。Chrome で画像選択、拡大縮小、ドラッグ、配置確定、PNG ダウンロード、A4 1 ページの印刷プレビューも確認しました。保存した PNG は 2480 × 3508 px、299.9994 dpi（整数の pixels/m による丸め）でした。

外部ライブラリへの依存はありません。表示用フォントのみ Google Fonts を使い、取得できない場合はシステムフォントで表示します。

プロジェクト保存については、画像本体・寸法・配置・倍率・移動量の往復保存、形式・バージョン・用紙設定の検証、破損時の復元中断を自動テストしています。Chrome でも画像入りのプロジェクトを開いて再保存し、画像データを含む全フィールドの一致を確認しました。
